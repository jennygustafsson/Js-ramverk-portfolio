# Portfolio

## Projektbeskrivning

En portfolio där jag har samlat 6 st projekt från utbildningen.

Sidan har fyra delar:

- **Hem** med rubriken Om mig
- **Om mig** med en bild och en kort text om utbildningen
- **Projekt** med sex projektkort
- **Kontakt** med länkar till mail, GitHub och LinkedIn

Varje projektkort visar en bild, en titel, en kort text, tekniker och en länk till repot på GitHub. Bilderna på projekten är AI-genererade. Projekten ligger i en egen fil och ritas ut som en lista. Ovanför korten går det att filtrera på en teknik i taget, eller visa alla.

## Tech stack

- React
- TypeScript
- Vite
- CSS 

React används för komponenterna. TypeScript används för datan och props. CSS används för stylingen, och sidan fungerar både på mobil och dator.

## Köra projektet lokalt

Öppna projektmappen i terminalen och kör:

```bash
npm install
npm run dev
```

`npm install` hämtar paketen. `npm run dev` startar sidan lokalt. Adressen visas i terminalen: http://localhost:5173.
